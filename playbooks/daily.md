# Daily Playbook

## 0500 to 0600: Morning routine

Do all the following in order:
- Brush teeth first thing in the morning
- Make coffee
- Morning pages (freewriting in journal at least one full page)
- Clean up desk
- Eat the frog (hardest thing to do that day)
- Shower
- Hide smoking supplies
- Get ready for first sprint (be very serious about this)
    - Finish coffee and put in sink
    - Fill water bottle
    - Choose music
    - Get distractions away

## 0600 to 0900: Work on daily goal

Do all the following in order:
- Get OBS ready to record
- Start task for 5 minutes
- Start recording, full screen camera
- Plan out task for two hour window, half screen camera
- Execute, producing artifact, quarter screen camera
- End recording

## 0900 to 1800: Software engineering (day job, personal projects)

As long as the focus is always on building a software artifact, work can be freeform. Note: configuration should be backgrounded.

## 1800 to 2100: Freeform

If you start on a task at this point, stop and think if it could be tomorrow's daily goal.

Make sure to perform the daily review and transcribe into the monthly note.

## 2100 to 2200: Night routine

Do all the following in order:
- Take melatonin
- Prepare whiteboard:
    - Frog -> the thing you most don't want to do.
    - Daily goal -> something concrete and presentable.
- Start on tomorrow's goal for 5 minutes.
- Prepare side table:
    - Phone charged with alarms set.
    - Pre-pasted toothbrush.
    - Filled water bottle.
- Prepare the desk:
    - Monitor shows CURRICULUM.md#Daily Schedule.
    - Ashtray and all smoking supplies in the drawer.
    - Rubbish thrown.
    - Corners empty.
    - Journal on desk with pen, date and daily goal pre-written.
    - Keyboard charging.
